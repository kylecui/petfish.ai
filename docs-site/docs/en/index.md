## What is PEtFiSh?

PEtFiSh is an always-on AI companion that runs a **Companion Gateway** before every interaction — sensing capability gaps, guarding context integrity, and blocking sycophantic responses. It ships with 12 skill packs covering deployment, research, course development, writing, and more.
