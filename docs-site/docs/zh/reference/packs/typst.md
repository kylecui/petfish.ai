# typst

Markdown转PDF — 通过pandoc+Typst pipeline，支持中英文混排、图表编号、drawio导出。

| 字段 | 值 |
|---|---|
| 包名 | `typst-pdf-builder` |
| 别名 | `typst` |
| 版本 | 1.0.1 |
| 技能数 | 1 |
| 兼容性 | opencode |

## 安装

```bash
uv run https://raw.githubusercontent.com/kylecui/petfish.ai/master/install.py --pack typst --detect
```
