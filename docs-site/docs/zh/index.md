**你的AI伙伴** — 从第一个commit到最终交付，胖鱼始终在场。

不是工具箱，是伙伴。工具被调用，胖鱼始终在场。

## 什么是PEtFiSh？

PEtFiSh是一个始终在线的AI伙伴，在每次交互前运行**伙伴网关（Companion Gateway）**——感知能力缺口、守护上下文完整性、阻止迎合式回答。附带16个技能包，覆盖部署、研究、课程开发、写作等场景。
