# 快速开始

PEtFiSh是一个AI伙伴——它不是被动等你调用的工具箱，而是在每一次交互中都在场的常驻伙伴。

## PEtFiSh做什么

大多数AI技能工具是被动的：安装、调用、祈祷agent记得用。PEtFiSh不一样。它的**Companion Gateway**在每条消息前自动运行，提供：

- **上下文守护** — 检测话题漂移，防止跨话题污染
- **能力缺口感知** — 在失败发生前发现缺失的技能
- **失败恢复** — 捕获上一轮的错误并推荐修复方案
- **反迎合** — 在盲目认同你的假设之前先暂停思考

在这个始终在线的层之上，PEtFiSh提供**12个技能包**，覆盖课程开发、部署运维、研究工作台、演示文稿、写作风格等领域——共96个技能，支持8个AI平台。

## 适合谁

PEtFiSh适合使用AI编码助手（OpenCode、Claude Code、Cursor、Codex、Copilot、Windsurf、Antigravity）的开发者和团队，如果你想要：

- **结构化工作流** — 不是临时提示词，而是可重复的技能驱动流程
- **质量护栏** — lint、安全审计、信任治理，确保AI技能的质量
- **跨平台一致性** — 同一套技能在8个平台上通用
