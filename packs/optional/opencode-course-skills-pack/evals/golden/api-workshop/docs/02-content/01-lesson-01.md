# 第 1 课：从业务域到资源清单

## 目标

完成本课后，学员能够将一个订单业务域拆解为资源与集合，并给出符合约定的 URI 草案。本课目标对应模块一目标。

## 示例

以"订单、订单项、用户、支付单"为例演示资源建模四步法，产出：

```text
/users
/users/{id}/orders
/orders/{id}/items
/payments/{id}
```

## 练习

1. 列出你负责业务域的候选名词清单。
2. 按四步法筛出资源，标注集合与单体的关系。
3. 为每个资源写出 URI 并说明命名理由。

## 时长

60 分钟（概念 15 分钟 + 示例 15 分钟 + 工作坊练习 30 分钟）。
