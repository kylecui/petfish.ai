# 澄清问题库（Clarification Bank）

用途：orchestrator 的 Gate 1（执行帧澄清）按课程类型选题，每轮只问一个问题，最多 3 轮。
选择原则：优先问对下游大纲/内容/实验影响最大、且用户最可能已有答案的问题。

## standard-training（标准培训）

1. 学员的技能基线是什么（零基础 / 在职提升 / 混合水平）？
2. 培训结束后，学员应当能独立完成什么可观察的行为？
3. 总课时与单次时长的硬约束是多少？

## workshop（工作坊）

1. 工作坊的交付形式是什么（现场 / 线上 / 混合，单场还是系列）？
2. 实验环境是否已就绪（设备、账号、软件版本、网络）？
3. 已有多少可复用的素材与旧讲义？

## k12（基础教育）

1. 目标学段与学生的先修基础是什么？
2. 测评偏好是什么（随堂测、作品展示、项目、纸笔考试）？
3. 质量标准由谁定义（学校教研组 / 机构 / 家长预期）？

## vocational（职业培训）

1. 学员的岗位目标与当前技能差距是什么？
2. 实训环境与真实生产环境的差距有多大？
3. 结课测评偏向证书考试还是作品集？

## 覆盖映射

- 受众基线：standard-training Q1、k12 Q1、vocational Q1
- 成功行为定义：standard-training Q2、vocational Q1
- 课时约束：standard-training Q3、workshop Q1
- 测评偏好：k12 Q2、vocational Q3
- 素材存量：workshop Q3
- 交付形式：workshop Q1
- 实验环境：workshop Q2、vocational Q2
- 质量 bar：k12 Q3
