# 题目质量分析参考（item-quality-guide）

> 定位：`course-assessment-design` 的按需参考层。题目写完不等于题目合格——本文件给出考后/评审阶段的量化指标与决策规则。**不内联进SKILL.md正文。**

## 1. 难度指数（P值）

- 定义：答对人数 / 作答总人数。P越高题越易。
- 合格区间：0.3 ≤ P ≤ 0.9；P<0.3偏难，P>0.9偏易。
- 决策：连续两个批次P<0.2或P>0.95 → 修订题干或淘汰。
- 注意：P值低≠题好——先排查歧义干扰项和超纲，再谈"区分高手"。

## 2. 区分度（D值）

- 定义：高分组（前27%）答对率 − 低分组（后27%）答对率（extreme groups对比法）。
- 合格区间：D ≥ 0.3 良好；0.2-0.3 需修订；D < 0.2 淘汰。
- 危险信号：D为负（低分组反而更对）→ 题干或正确选项存在误导，立即停用并复盘。
- 替代口径：总分与单题得分的点二列相关（point-biserial）≥0.2为可用。

## 3. 选项分析（MCQ/多选专用）

- 每个干扰项的选择率应>5%；无人选择的干扰项是"死选项"，应改写或替换。
- 正确选项被均匀分布在不同位置（A/B/C/D各约25%），不扎堆。
- 高分组集中选某个干扰项 → 该项"过强"，检查是否存在双正确答案争议。

## 4. 锚题等值化与难度漂移

- 用途：跨批次比较"学员水平"前，先用锚题校准两批次难度是否等值。
- 操作：锚题（anchor: true）不复用曝光、不进练习卷；两批次锚题P值差>0.15 → 判定批次间难度漂移，比较结论需加注。
- 曝光控制：高频复用题进入学员备考视野后P值虚高，锚题池应轮换并监控选择率异常。

## 5. 信度与效度的最低自检

- 信度：同卷内部一致性（如分半/克隆巴赫α；客观题全卷可用KR-20，分半法用Spearman-Brown校正）——课程场景α≥0.7可用；低于0.6说明题目测量目标过于分散，回查目标绑定字段。
- 效度：内容效度为主——每题都能挂到objective_id即基本合格；不要宣称"预测效度"除非有追踪数据。
- 诚实边界：小班（N<30）统计指标仅供方向性参考，不作为淘汰题目的唯一依据。

## 6. 评审阶段（无作答数据时）的替代检查

- 逐题标注预期P值（易0.8/中0.6/难0.4），与难度字段一致性核对。
- 请一位未参与出题的同行盲做全卷，记录每题用时与犹豫点。
- 对照蓝图的Bloom分布，确认认知层级没有系统性偏高或偏低。

## 7. 数据记录与复算（spreadsheet列约定）

考后把作答数据落成一张表，每行一题，列约定如下：

| 列名 | 含义 | 计算式 |
|---|---|---|
| item_id | 题目编号 | — |
| n_total | 作答人数 | count |
| n_h / n_l | 高/低分组人数 | n_total × 0.27 |
| p_all | 全体难度 | 答对数 / n_total |
| p_h / p_l | 分组难度 | 各组答对数 / 组人数 |
| d_index | 区分度 | p_h − p_l |
| rbis | 点二列相关 | 由统计工具或 `=CORREL()` 近似 |
| opt_a…opt_e | 各选项选择率 | 该选项人数 / n_total |

复算示例（n_total=50，答对31）：p_all = 31/50 = 0.62；p_h = 0.79，p_l = 0.41 → d_index = 0.38（良好，保留）。若d_index = −0.07 → 立即停用并复盘题干。

判定速查：p_all∈[0.3,0.9] 且 d_index≥0.3 → 保留；任一越界 → 进修订队列；d_index<0 或 0.2以下连续两批次 → 淘汰。
