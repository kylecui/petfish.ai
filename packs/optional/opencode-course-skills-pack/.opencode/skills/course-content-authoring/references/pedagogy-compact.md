# 教学法速查（pedagogy-compact）

> 定位：`course-content-authoring` 的按需参考层。编写或评审课时内容时查用，**不内联进SKILL.md正文，不整篇塞进生成提示词**（OpenMAIC 30KB提示词教训：参考层按需读，正文只留一行索引）。

## 1. Bloom动词表（六层×可测动词）

课程与课时目标必须使用可测动词；"了解/掌握/熟悉/懂得"不可测，出现即改写。

| 层级 | 可测动词（中/英） | 目标句式示例 |
|---|---|---|
| 记忆 Remember | 列出 list / 辨认 identify / 定义 define / 命名 name / 复述 recall | 学员能列出Git三种重置模式的名称 |
| 理解 Understand | 解释 explain / 举例 exemplify / 归类 classify / 总结 summarize / 对比 compare | 学员能用自己的话解释软链接与硬链接的差异 |
| 应用 Apply | 执行 execute / 实现 implement / 演示 demonstrate / 使用 use / 运算 calculate | 学员能在给定分支上执行一次合并并解决冲突 |
| 分析 Analyze | 区分 differentiate / 拆解 decompose / 归因 attribute / 诊断 diagnose / 调试 debug | 学员能从失败日志定位导致构建断裂的配置项 |
| 评价 Evaluate | 检查 check / 评判 critique / 论证 justify / 择优 select / 审查 review | 学员能论证在两个方案中选A而非B的两个理由 |
| 创造 Create | 设计 design / 构建 build / 编写 compose / 生成 generate / 规划 plan | 学员能为给定需求设计一套带评审门的分支策略 |

用法：目标句式 = 学员（audience）+ 可测动词 + 对象 + 条件 + 合格标准。
红线：下层动词不冒充上层（"能复述架构图"≠"能设计架构"）。

## 2. 认知负荷三原则

### 2.1 内在负荷（intrinsic load）——内容本身的复杂度

- 来源：概念元素间的交互复杂度，不由呈现方式决定。
- 应用：分块（chunking）——把高交互内容拆成"先部分后整体"；先教子技能，再组合成完整任务。
- 示例：教正则回溯，按"线性匹配→量词回溯→嵌套量词灾难"三段递进，不要开篇就甩catastrophic backtracking案例。

### 2.2 外在负荷（extraneous load）——呈现方式引入的浪费

- 来源：糟糕排版、术语跳变、图文分离、频繁切换符号体系。
- 应用：临近原则（说明文字紧贴图示，不跨页）；术语首次出现即定义且全文一致；同一例子只用一套记号。
- 示例：先称"暂存区"就全文"暂存区"，不中途换用"索引/index/staging"混称。

### 2.3 关联负荷（germane load）——建构图式的有效投入

- 来源：学习者主动组织、比较、自我解释投入的认知努力。
- 应用：加自我解释提示（"这行为什么要先rebase？"）；给对比案例（好/坏实践并排呈现）。
- 示例：示例代码后留一行"这行为什么不能用X替代"的提问，比再讲一遍更有效。

三原则口诀：**先拆内在（分块）、再削外在（呈现干净）、后投资关联（逼学生组织）**。

## 3. 样例-练习配比（worked example渐退序列）

新手期样例优先，熟练后练习比重递增（expertise reversal：给熟手堆样例反而有害）。

标准渐退四段（一个知识单元内按序铺开）：

1. **Worked example（完整样例）**：每步附"为什么"，学生只读。
2. **Completion（补全题）**：给一半步骤，学生补关键步骤。
3. **Faded（渐褪题）**：只给框架/起点，学生完成主体，提示可查。
4. **Independent（独立题）**：只有任务描述，学生全流程完成。

配比与退阶规则：

- 一个课时的4道练习按1:1:1:1铺开；时间紧保前2段。
- 独立题必须带评分标准（对齐SKILL.md的Done-Checklist）。
- 上一段正确率≥80%才进下一段；否则同段换题重练。

## 4. 误解前置策略（misconception-first）

先暴露误解再给正解，比直接讲正解留存率更高。

操作三步：

1. **收集**：从往期QA、答疑、论坛高频错误中提取该知识点的典型误解（每课时≥1个）。
2. **前置呈现**：讲正确概念前，先给"直觉但错"的写法/判断，让学生先承诺一个答案（commit），再揭示错误。
3. **归因**：不只说"这是错的"，要讲清"直觉为什么错、错在哪一步推理"。

示例：教浮点比较，先问`0.1+0.2==0.3`返回什么，学生承诺后再揭示精度表示问题。
红线：误解呈现必须显式标注"这是典型错误"，不得以无标记方式混入正文造成误学。

## 5. 检索练习与间隔（retrieval practice & spacing）

### 5.1 检索练习（testing effect）

- 原则：主动检索比重看一遍有效；每次检索都强化记忆路径。
- 应用：课时小结改为2-3问自测（答案放页脚翻转或instructor-pack）；跨课时开头用3分钟提问上一课核心。
- 禁忌：检索题≠高难度题——低风险、允许出错的练习场最有效。

### 5.2 间隔（spacing effect）

- 原则：同一内容多次分散接触优于集中一次（对抗突击式遗忘）。
- 应用：核心概念在后续模块的练习、labs、测评中至少再现2次（换语境再现，不是原题重复）；在大纲层面规划"再现点"。
- 衔接：`course-outline-design/references/assessment-planning.md`的锚题（anchor items）即间隔复测的载体。
