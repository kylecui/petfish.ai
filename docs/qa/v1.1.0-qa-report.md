## 6. 发现的问题

### P0 — get_memory_context 默认不可用 ([#144](https://github.com/kylecui/petfish.ai/issues/144))

- `tools/list` 无条件列出 `get_memory_context`，但 handler 仅在 `memory_context_enabled=True` 时注册
- 所有 sub-feature flags 默认 `False` → `memory_context_enabled = True AND (False OR False) = False`
- 调用返回 `"Unknown tool: get_memory_context"`
- 修复：config 需额外设置 `"enable_tiered_retention": true` 和 `"enable_budget_allocation": true`

### P2 — safety-guard.md 未部署

- 源仓库 `.opencode/agents-rules/safety-guard.md` (75行) 存在，但安装脚本未将其部署到项目
- `system-prompt-rules.ts` 的 TOPIC_TO_RULES 映射中也没有 safety-guard 条目
- 安全守卫测试 SG-01~04 无法执行

### P2 — 文档路径错误

| 文件 | 问题 |
|------|------|
| `docs/qa/reference-index.md` | skill-registry 路径写 `mcp/skill-registry/`，实际在 `.opencode/mcp/skill-registry/` |
| 同上 | usage-cost 同理 |

### P3 — companion MCP 未随 pack 安装

- skill-registry + usage-cost MCP 服务器在 companion pack 源码 `.opencode/mcp/` 下，但安装未部署到项目
- 需从源码 repo 手动运行

### P3 — API 参数不一致 (usage-cost MCP)

- `record_usage` 参数名为 `input_tokens`/`output_tokens`，与常规 `tokens_in`/`tokens_out` 命名不一致
