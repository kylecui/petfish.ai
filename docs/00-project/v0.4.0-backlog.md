## 风险登记

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| MCP server启动失败导致always-on层不工作 | Layer 1降级为无感知 | AGENTS.md中增加fallback规则：MCP不可用时退化为手动模式，不报错 |
| topic_detect过度触发 | 用户体验差 | 严格阈值 + evals测试覆盖 + medium等级只提示不执行 |
| JSON文件冲突（多session并发写入） | 数据丢失 | 文件级锁 + atomic write（写temp文件再rename） |
| .ai-context/目录过大 | git仓库膨胀 | archive操作清理旧context package + 安装时自动添加.gitignore |
| Agent忽略AGENTS.md中的always-on指令 | 话题治理不生效 | evals测试agent遵从率，指令措辞迭代优化 |
| merge/archive/bridge低置信度误检测 | 执行错误的上下文操作 | 低置信度类型强制用户确认，不自动执行 |
